01 · Projeto pessoal · em desenvolvimento

MatheusFlow: gestão de chamados.

Um sistema web para registrar clientes e solicitações de serviço, acompanhar o andamento dos chamados e visualizar indicadores em um dashboard.

  • Cadastro, busca e filtro de chamados por status
  • Indicadores de pendências, andamento e conclusão
  • Interface responsiva construída com HTML, CSS e JavaScript

Aplicação local com API Python e banco SQLite. A demonstração hospedada no GitHub não executa a API.

MindFlow: encontre seu fluxo.

Um jogo de blocos pensado para pequenas pausas e momentos de concentração. Encaixe peças, complete linhas e colunas, crie combos e avance por novos níveis.

  • Partidas rápidas com dificuldade progressiva
  • Recorde salvo no próprio aparelho
  • Experiência responsiva e instalável no celular

Urbanix: ocorrências urbanas no mapa.

Um protótipo para registrar ocorrências urbanas, localizá-las no mapa e consultar os dados por categoria, período e bairro.

  • Cadastro com categoria, gravidade, foto opcional e ponto no mapa
  • Filtros, indicadores, gráficos e fila por prioridade experimental
  • Prévia estática no GitHub: entre com adm / adm
