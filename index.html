Projeto pessoal · em desenvolvimento

MatheusFlow: gestão de chamados.

Um sistema web para registrar clientes e solicitações de serviço, acompanhar o andamento dos chamados e visualizar indicadores em um dashboard.

Cadastro, busca e filtro de chamados por status
Indicadores de pendências, andamento e conclusão
Interface responsiva construída com HTML, CSS e JavaScript

Aplicação local com API Python e banco SQLite. Para usar, inicie o servidor no computador; os chamados ficam no arquivo serviceflow.db. A demonstração hospedada no GitHub não executa a API.
